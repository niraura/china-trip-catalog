# 中国旅行の候補地

12月の中国でできる体験を150件並べたカタログ。場所ではなく「やりたいこと」から行き先を逆算するための道具。

**https://niraura.github.io/china-trip/**

## できること

- **タグで絞る** — 性質・地域・気分・12月適性・所要時間・予算・観光地度・屋内外の8軸。同じ軸のなかは OR、軸をまたぐと AND
- **キーワード検索** — 体験名・説明・地名をまとめて検索
- **☆** — 気になったものに印を付ける。「☆のみ」で絞り込める
- **表モード** — 実務情報を一覧で比較。列見出しで並べ替え
- **位置関係** — 掲載している地域の概略図

## ☆の保存について

☆はブラウザの localStorage に保存される。同じブラウザで開けば残るが、**端末やブラウザをまたぐと引き継がれない**。

移すときは「☆の控え」パネルから:

- **選択をURLにする** — 現在の☆を載せたURLをコピーする。相手に送れば同じ☆の状態で開く
- **ファイルに保存 / コピー** — 一覧をテキストで持ち出す。「ファイルから復元」または貼り付けて「この内容で☆を置き換える」で戻せる

URLには150件の並びに対するビットマップと版ハッシュが入っている。カードを増減・並べ替えたあとの古いリンクは、別のカードを☆にしてしまわないよう適用せず警告を出す。

## 構成

`index.html` 1枚のみ。CSS・JavaScript・150件のデータをすべてインラインで持ち、外部リソースを一切読み込まない。ビルド不要でそのまま GitHub Pages から配信している。
