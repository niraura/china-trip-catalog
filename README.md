# 中国旅行の候補地

12月の中国でできる体験を500件並べたカタログ。場所ではなく「やりたいこと」から行き先を逆算するための道具。

**https://niraura.github.io/china-trip-catalog/**

## できること

- **タグで絞る** — 性質・地域・気分・有名度・12月適性・所要時間・予算・観光地度・屋内外の9軸。同じ軸のなかは OR、軸をまたぐと AND
- **有名度** — 誰もが知る定番（5）から、地元の人しか知らないもの（1）までの5段階。各段階100件ずつある
- **キーワード検索** — 体験名・説明・地名をまとめて検索
- **☆** — 気になったものに印を付ける。「☆のみ」で絞り込める
- **表モード** — 実務情報を一覧で比較。列見出しで並べ替え
- **位置関係** — 掲載している地域の概略図

## 有名度の目安

| | 意味 | 例 |
|---|---|---|
| 5 | 定番 | 兵馬俑、故宮、漓江、成都の火鍋 |
| 4 | 有名 | 洛陽橋、王家大院、大澳の水上家屋 |
| 3 | 中国では有名 | 沙渓古鎮、洛陽の水席、彭鎮の老茶館 |
| 2 | 通好み | 増冲鼓楼、霞浦の灘塗、佛光寺 |
| 1 | 地元だけが知る | 太符観、恭城の油茶、社区の食堂 |

## ☆の保存について

☆はブラウザの localStorage に保存される。同じブラウザで開けば残るが、**端末やブラウザをまたぐと引き継がれない**。

渡すときは右端の **「共有」** を押す。LINEで送る／URLをコピー（対応環境ではOSの共有シートも）から選べる。

受け取った側がそのURLを開くと **閲覧専用** になる。共有された☆が表示されるだけで、付け外しはできず、そのブラウザに保存されている☆には一切触れない。「自分の☆に戻る」で通常表示へ戻る。

URLには500件の並びに対するビットマップと版ハッシュが入っている。カードを増減・並べ替えたあとの古いリンクは、別のカードを☆にしてしまわないよう適用せず警告を出す。

## 構成

`index.html` 1枚のみ。CSS・JavaScript・500件のデータをすべてインラインで持ち、外部リソースを一切読み込まない。ビルド不要でそのまま GitHub Pages から配信している。
